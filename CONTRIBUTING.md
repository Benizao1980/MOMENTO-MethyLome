# Contributing

MOMENTO is early-stage research software. Priorities are: stabilise schemas; validate PacBio import; count motif opportunities from FASTA; add ONT bedMethyl import; add MTase/phase integration; add phylogeny-aware association models.

Platform parsing belongs in `src/momento/io/`; biological analysis should remain platform-independent; provenance must be retained; examples must use public-safe or synthetic data.
